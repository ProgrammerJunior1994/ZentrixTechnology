# INTESYS - Sitio web informativo

Sitio web estático creado para INTESYS (Integradores de Sistemas y Servicios).

## Incluye
- Inicio / presentación de la empresa
- Servicios de internet
- Paquetes mostrados en la publicidad proporcionada
- Sección de cibercafé
- Galería preparada para fotografías reales del negocio
- Información sobre INTESYS
- Contacto
- Formulario para contratar/solicitar información por WhatsApp
- Diseño responsive para computadora, tablet y celular

## WhatsApp
El número configurado en `js/script.js` es:

315 113 2995

La página genera enlaces de WhatsApp con mensajes prellenados.

## Cómo abrirla
1. Extrae el ZIP.
2. Abre `index.html` en un navegador.

También puedes abrir la carpeta con Visual Studio Code y usar Live Server.

## Fotografías
Las tres imágenes proporcionadas inicialmente están dentro de `assets/`:
- logo-intesys.png
- promocion-paquetes.png
- promocion-internet.png

Cuando tengas fotografías reales del establecimiento, puedes colocarlas en `assets/` y sustituir las imágenes de la galería en `index.html`.

## Nota sobre precios
Los paquetes de $350, $500 y $800 corresponden a la publicidad entregada para el diseño. Si los precios o velocidades cambian, edita la sección `#internet` de `index.html`.
